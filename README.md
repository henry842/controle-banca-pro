# 💰 Controle Banca Pro

Gerencie sua banca de apostas esportivas, veja lucros, ROI e stake recomendado.

🔗 **Acesse o app:** https://henry842.github.io/controle-banca-pro/

## 🎯 Funcionalidades

- Registro de apostas e resultados
- Cálculo automático de lucro e ROI
- Stake recomendado com base na banca atual
- Visualização de performance em tempo real

## 🛠️ Tecnologias

`HTML` `CSS` `JavaScript`

## 🚀 Como executar

```bash
git clone https://github.com/henry842/controle-banca-pro.git
cd controle-banca-pro
# Abra o arquivo index.html no navegador
```
